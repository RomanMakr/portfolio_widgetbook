# Portfolio workspace artwork

Both images in this directory were generated with the built-in image generation
tool for this project. `portfolio_devices.png` is the transparent landing hero
illustration; its full prompt is in [DEVICE_PROMPT.md](DEVICE_PROMPT.md).

`developer_workspace.png` was generated using the built-in image generation tool
for this project's public portfolio hero. It is not a photograph of the owner.

## Generation prompt

Use case: photorealistic-natural. Asset type: wide hero photograph for a dark
purple software engineer portfolio website. Create a cinematic, photorealistic
modern developer workspace at night: two desktop monitors with tiny unreadable
multicolored code, a black ergonomic chair, a clean dark desk, a leafy plant on
the left, and a soft purple-pink neon code-symbol light on the wall. View straight
on at a slight angle, desk and monitors concentrated center-right, atmospheric
near-black violet shadows blending at the left edge for an adjacent text column.
Violet and magenta accent lighting, restrained premium professional mood,
realistic materials. Wide landscape composition roughly 3:2. No people, no legible
words, no watermarks, no logos, no UI frame or webpage surrounding the photograph.
